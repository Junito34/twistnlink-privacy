# TwistNLink Privacy Policy

Static, bilingual privacy-policy page for the Android game **TwistNLink**
(`com.junito.twistnlink`). The page contains no JavaScript, cookies, analytics,
forms, or third-party assets.

## Publish with GitHub Pages

1. Create a public GitHub repository named `twistnlink-privacy` under the
   `AnthonyQuattrochi` account.
2. Push this directory to the repository's `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select
   **main** and **/(root)**.
4. The expected public URL is:
   `https://anthonyquattrochi.github.io/twistnlink-privacy/`

## Before publishing

- Confirm that the Google Play developer name is accurately represented by
  “Anthony Quattrochi / Junito”. Google requires the app or the developer entity
  shown on the store listing to be named in the privacy policy.
- If a dedicated support email exists, replace the GitHub Issues contact link
  with that email address. A public support address is preferable for private
  data-subject requests.
- Keep the Google Play **Data safety** declaration consistent with this page and
  with the SDKs bundled in each release.
- Update the date and provider list whenever the app's data practices change.
